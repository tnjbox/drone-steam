## 使用原則

1. 保留原始 `LICENSE` 與原作者文件。
2. 不直接把第三方原始碼當成本專案自行創作的程式。
3. 教材版韌體應另建資料夾，清楚標示修改內容、日期與授權。
4. 原始程式內的馬達測試、解鎖與安全參數，未經實體驗證前不得直接作為學生操作版本。
5. 這份快照尚未完成獨立編譯驗證；目前資料中可見 MAVLink 相關函式引用，但未找到對應實作檔，後續應先建立可重現的建置環境。
