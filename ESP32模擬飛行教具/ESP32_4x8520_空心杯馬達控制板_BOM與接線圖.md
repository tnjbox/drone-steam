# ESP32 + 4×8520 空心杯馬達控制板 BOM 與完整接線圖

## 1. 專案目標

建立一塊可由 **ESP32 輸出 4 路 PWM**，分別控制 **4 顆 8520 空心杯有刷馬達** 的控制板。

此版本定位為：

- 四軸動力實驗平台
- PWM 與馬達動力關係教具
- 後續可再加入 IMU / PID / Motor Mixing

> 本方案不需要飛控板，採 **ESP32 + 4 路 N-MOSFET 低側開關** 架構。

## 2. 建議系統規格

### 馬達電源
- 建議先以 **1S 鋰電等級** 為主：
  - **3.7V 標稱**
  - **4.2V 滿電上限**
- **第一次測試不要超過 4.2V**

### 控制板供電
- ESP32 建議：
  - **USB 5V 獨立供電**
  - 或穩定 5V 模組供電
- 馬達電源與 ESP32 **必須共地**

### PWM 建議
- 每顆馬達 1 路 PWM
- 建議初始設定：
  - **頻率：10 kHz**
  - **解析度：8 bit**
- 初次測試建議先限制：
  - **0 ~ 60% duty**

| 馬達 | GPIO |

| M1 | GPIO25 |

## 6. 二極體方向說明

Flyback 二極體方向：

- **SS14 陰極（有條紋的一端）接 +VMOTOR**
- **SS14 陽極接 MOSFET Drain / 馬達負端**

```text
馬達負端 ──|>|── +VMOTOR
```

用途：
- 吸收馬達斷電時產生的反向感應電壓
- 保護 MOSFET
- 降低雜訊

## 9. 實體接線清單

### M1
- GPIO25 → 100Ω → MOSFET1 Gate
- MOSFET1 Gate → 10kΩ → GND
- MOSFET1 Source → GND
- MOSFET1 Drain → Motor1 負端
- Motor1 正端 → +VMOTOR
- SS14：陽極接 Drain、陰極接 +VMOTOR
- 0.1µF：並聯在 Motor1 正負端

### M2
- GPIO26 → 100Ω → MOSFET2 Gate
- MOSFET2 Gate → 10kΩ → GND
- MOSFET2 Source → GND
- MOSFET2 Drain → Motor2 負端
- Motor2 正端 → +VMOTOR
- SS14：陽極接 Drain、陰極接 +VMOTOR
- 0.1µF：並聯在 Motor2 正負端

### M3
- GPIO27 → 100Ω → MOSFET3 Gate
- MOSFET3 Gate → 10kΩ → GND
- MOSFET3 Source → GND
- MOSFET3 Drain → Motor3 負端
- Motor3 正端 → +VMOTOR
- SS14：陽極接 Drain、陰極接 +VMOTOR
- 0.1µF：並聯在 Motor3 正負端

### M4
- GPIO32 → 100Ω → MOSFET4 Gate
- MOSFET4 Gate → 10kΩ → GND
- MOSFET4 Source → GND
- MOSFET4 Drain → Motor4 負端
- Motor4 正端 → +VMOTOR
- SS14：陽極接 Drain、陰極接 +VMOTOR
- 0.1µF：並聯在 Motor4 正負端

### 共用
- ESP32 GND → 馬達電源 GND
- ESP32 以 USB 5V 供電
- 馬達由獨立 3.7V~4.2V 電源供電
- 馬達電源端加 470~1000µF 電解電容
- 馬達電源端加 0.1µF 陶瓷電容

## 11. 初次上電與測試流程

### 第一步：不接馬達
先確認：
- ESP32 可正常上電
- PWM 腳位輸出正常
- Gate 沒有誤接
- 沒有短路

### 第二步：只接一顆馬達
只測 M1：
- 20%
- 40%
- 60%

觀察：
- 馬達是否正常轉動
- MOSFET 是否發熱
- 是否有異常火花或重啟

### 第三步：接兩顆
測試 M1 + M2 同時運轉。

### 第四步：接四顆
先限制最大 duty 在 60%。

### 第五步：再逐步提高
如系統穩定，再測：
- 70%
- 80%

> 不建議一開始直接 100%。

## 12. 重要注意事項

1. **不要用 ESP32 板子的 3.3V 直接供馬達**：馬達電流太大，可能造成電壓掉落、ESP32 重開機甚至損壞。
2. **一定要共地**：ESP32 GND 與馬達電源 GND 必須共地。
3. **MOSFET 選型**：優先選 Si2302CDS 或 AO3400A；不建議 2N7002、BSS123、IRF520 模組。
4. **初次測試先無槳**：若後面加槳測試，先做好固定與防護。
5. **8520 馬達電壓不要任意拉高**：若為 1S 系統，建議先控制在 3.7V 標稱、4.2V 上限。
