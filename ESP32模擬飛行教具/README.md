# ESP32 模擬飛行教具

本資料夾用於集中管理無人機課程中與 **ESP32 模擬飛行教具** 有關的技術文件、硬體規格、韌體、測試紀錄與後續 PID／IMU 實驗資料。

## 目前規畫

1. ESP32 四路 PWM 控制
2. 4×8520 空心杯馬達 + MOSFET 驅動
3. 四軸 Motor Mixing（Throttle / Roll / Pitch / Yaw）
4. 加入 6 軸或 9 軸 IMU
5. 單軸 PID 平衡
6. Roll / Pitch 雙軸 PID
7. 限制式懸浮／平衡教具
8. 後續與 Blockly Lab 整合

## 文件

- `ESP32_4x8520_空心杯馬達控制板_BOM與接線圖.md`：第一版四馬達 PWM 控制板 BOM、電源與完整接線規畫。

> 本教具以教學與實驗為優先，不以自由飛行為第一階段目標；真實飛行可搭配既有商用無人機進行觀察與比較。
