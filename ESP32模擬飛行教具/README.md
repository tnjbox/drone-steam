# ESP32 模擬飛行教具

本資料夾用於集中管理無人機課程中與 **ESP32 模擬飛行教具** 有關的技術文件、硬體規格、韌體、測試紀錄與後續 PID／IMU 實驗資料。

## 目前規畫

1. ESP32 四路 PWM 控制
2. 4×8520 空心杯馬達 + MOSFET 驅動
3. 四軸 Motor Mixing（Throttle / Roll / Pitch / Yaw）
4. 加入 6 軸或 9 軸 IMU
5. 單軸 PID 平衡
6. Roll / Pitch 雙軸 PID
7. 限制式懸浮／平衡教具
8. 後續與 Blockly Lab 整合

## 文件

- `ESP32_4x8520_空心杯馬達控制板_BOM與接線圖.md`：第一版四馬達 PWM 控制板 BOM、電源與完整接線規畫。
- `reference/README.md`：第三方開源參考資料的來源、版本、驗證狀態與使用原則。
- `reference/ESP32迷你無人機_XW_Z1_V2.0/`：XW_Z1_V2.0 原理圖、組裝文件與 ESP32 飛控程式碼快照。此目錄保留作為分析基準，不等同於後續自行開發的學生版韌體。

## 資料分層

```text
ESP32模擬飛行教具/
├─ README.md
├─ ESP32_4x8520_空心杯馬達控制板_BOM與接線圖.md
└─ reference/
   ├─ README.md
   └─ ESP32迷你無人機_XW_Z1_V2.0/
      ├─ SCH_XW_Z1_V2.0.pdf
      ├─ 无人机套件组装及使用说明.pdf
      └─ 程式碼/
```

後續自行修改的教具韌體、實驗紀錄與教材文件，應建立在 `reference/` 之外；第三方原始資料僅作為功能研究、比對與授權追蹤依據。

> 本教具以教學與實驗為優先，不以自由飛行為第一階段目標；真實飛行可搭配既有商用無人機進行觀察與比較。
