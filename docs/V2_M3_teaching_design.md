# V2 M3｜四軸協同：一個動作怎麼變成四顆馬達輸出？

## 模組定位

M3 承接 M2 的「單顆 PWM 是控制命令，不等於推力」，進一步打開四馬達 Mixer。教學採兩層設計：

1. **任務解密**：先按下懸停、升降、平移與旋轉，觀察 FL／FR／RL／RR 的相對增減。
2. **Mixer 自由實驗**：再調整 Throttle、Roll、Pitch、Yaw，使用開源飛控公式計算四路輸出。

## 核心概念

- 四顆一起增減：改變總推力。
- 前後兩側形成差異：形成 Pitch 傾斜趨勢。
- 左右兩側形成差異：形成 Roll 傾斜趨勢。
- CW／CCW 旋轉組形成差異：形成 Yaw 旋轉趨勢。
- 水平移動是先傾斜，再由總推力產生水平分量。
- Mixer 輸出超過允許範圍時會被限制；裁切後不再保有理想差值。

## 與開源飛控對照

採用 `control.ino` 的四路混控符號：

```text
FL = T + R - P + Y
FR = T - R - P - Y
RL = T + R + P - Y
RR = T - R + P + Y
```

原始程式使用 0～1，線上實驗為方便閱讀改用 0～100 概念尺度。計算後同樣限制到有效範圍。

## 線上活動

- 九個固定任務：懸停、上升、下降、前進、後退、左移、右移、左旋、右旋。
- 顯示四顆馬達位置、旋向、概念輸出、相對基準變化、總和與差值類型。
- 自由調整 T／R／P／Y，觀察公式與輸出裁切。
- 保存觀察紀錄並下載 CSV。
- 教材頁只保留兩次預測與一句統整，避免把每個按鈕變成作答題。

## 證據限制與硬體待驗證

- 35、40、50、60、65 是概念輸出，不是安全起飛值。
- 模擬不代表真實推力、姿態角、傾斜速度或飛行距離。
- 真實四馬達差異、重心、槳葉、電池壓降、閉迴路姿態控制及安全限制，待硬體採購後驗證。
- 真實馬達測試須拆槳、限制輸出、具備 Arm／Disarm 與急停程序。

## 銜接 M4
