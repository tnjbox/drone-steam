# V2 M2 教學設計｜動力解密

## 核心問題

> 程式把 PWM 輸出調大，馬達真的會照比例變強嗎？

## 現階段定位

真實 XW_Z1_V2.0 硬體尚待採購，因此第一階段先完成線上教材與 PWM 模擬。模擬用於提出假設、理解 Duty 與規劃未來量測，不宣稱已取得 8520 馬達的啟動死區、推力、電流、溫升或安全上限。

## 學習流程

1. 分清楚程式已知與硬體待測。
2. 預測啟動門檻及 Duty 加倍的效果。
3. 將 Duty 換算成 10-bit PWM 命令。
4. 使用固定測點比較理想線性模型與馬達示意模型。
5. 判讀模擬證據的適用範圍。
6. 框列採購後需要驗證的數據。
7. 用一句話區分控制命令與真實動力。
8. 銜接 M3 四馬達 Mixer。

## 線上證據

- 固定 Duty：0%、10%、15%、25%、35%、45%；以 10%（門檻以下）與 15%（門檻以上）形成明確對照。
- 10-bit 約略命令值。
- PWM 高電位時間比例。
- 理想線性模型與含虛構啟動門檻的示意模型。
- 可下載的模擬紀錄 CSV。

## 模擬限制

- 12% 啟動門檻是教學用虛構參數。
- 示意效果不是轉速或推力單位。
- 波形時間尺度不是 78kHz 示波器畫面。
- 線上結果不能取代真實硬體量測。

## 硬體採購後補做

- 拆槳安全檢查。
- 單馬達互鎖與非阻塞計時停止。
- Emergency Stop、低電與斷線保護。
- 四顆馬達各自的啟動死區。
- 78kHz、10-bit PWM 波形。
- 電池壓降、電流、氣流／推力及溫升。
- 教師核准的最大 Duty 與單次測試時間。

## 學生最少紀錄

- 兩次預測。
- PWM Lab 模擬紀錄。
- 一句統整。
