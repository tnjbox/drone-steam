# V2 M6｜程控任務

## 定位

以任務需求產生循序、參數、迴圈、條件、除錯與停止規則的學習需要。M6 是任務層級演算法，不宣稱目前飛控已具備自主導航。

## 開源韌體邊界

- 已有 Web RC、Serial CLI、SBUS RC、Arm／Disarm、急停、RAW／ACRO／STAB 與 failsafe。
- `AUTO` 目前只有模式入口，未看到完整 Mission Executor。
- `ALTHOLD` 為預留／stub，Web 介面選擇時會退回 STAB。
- 尚無可靠定高、定點與航點導航，不可把格線模擬結果稱為真實飛行能力。

## 線上活動

1. 循序：組合起飛、前進、轉向與降落，逐步或連續執行。
2. 迴圈：設定多邊形邊數，觀察展開指令與 repeat 結構。
3. 條件：根據目標相對方位選擇左轉、右轉或前進，加入偏移後重新判斷。
4. 安全：最大步數、越界、未起飛移動、落地與停止狀態。
5. 保存任務結果並下載 CSV。

## 真實移植階梯

線上模擬 → 靜態檢查 → 拆槳輸出 → 限制式測試架 → 低輸出空曠場地 → 感測／定位成熟後的短任務。每一層都必須保留 Disarm、急停、低電、失聯與超時處理。
