# STEM創課－解密四軸無人機

以四軸無人機作為科技系統載具，從系統拆解、機體結構、動力、四軸協同、感測、回授控制、演算法到工程創新，建立一套以核心問題驅動的 STEAM 任務課程。

本專案不是以「飛行操作訓練」為主，而是希望學生透過實體觀察、組裝、量測、模擬、程式與工程改造，理解一架無人機為什麼能工作，以及不同子系統如何彼此合作。

## 課程模組

| 模組 | 主題 | 核心提問 |
|---|---|---|
| M0 | 系統解密 | 一架四軸無人機裡藏了什麼？ |
| M1 | 機體結構 | 怎樣的「身體」比較穩？ |
| M2 | 動力解密 | 螺旋槳如何把電變成推力？ |
| M3 | 四軸協同 | 四顆馬達要怎麼一起工作，才能讓無人機照我的意思移動？ |
| M4 | 感知世界 | 無人機怎麼知道自己飛多高、移動了多少？ |
| M5 | 智慧控制 | 機器怎麼自己修正？ |
| M6 | 程式與任務 | 如何讓無人機依照規則自己完成任務？ |
| M7 | 工程創新 | 同一套零件，可以變成什麼？ |

整體學習進程：

> 看懂系統 → 做出結構 → 理解動力 → 四軸協同 → 感知世界 → 智慧控制 → 演算法任務 → 工程創新

## 課程設計理念

1. **核心問題驅動**：每一模組先確定真正要破解的問題，再安排必要的觀察、實作、量測、模擬或創作。
2. **任務先行、鷹架伴隨**：知識鷹架在學生遇到認知瓶頸時提供，不作所有學生必讀的前置教材。
3. **證據導向**：鼓勵學生用現象、數據、模擬結果或工程作品回答「我怎麼知道」。
4. **低飛行依賴**：真實飛行僅作必要展示或驗證，主要學習發生在桌面探究、機電實作、系統分析與工程設計中。

## ESP32 教具研發資料

`ESP32模擬飛行教具/` 保存四路 PWM、8520 空心杯馬達、Motor Mixing、IMU、PID 與限制式平衡教具的研發文件。第三方開源無人機程式、原理圖及說明文件統一放在其 `reference/` 子目錄，與本專案自行開發的教材及韌體分開管理。

## 使用方式

### 學生

由 `index.html` 進入課程，建議依 M0 → M7 順序完成任務。各任務頁會依需要保存部分學習紀錄於瀏覽器本機。

### 教師

由 `teacher.html` 查看課程定位、模組設計脈絡、教師教學設計文件、鷹架、模擬器與實施提醒。

## 使用設備與技術

課程以 Gigo #1413-CN「無人機 2.0－micro:bit 編程遙控組」作為主要實作載具，並依模組需求搭配 micro:bit、ESP32、Arduino 或量測設備。

網站主要以 HTML、CSS、JavaScript 製作，並透過 GitHub Pages 發布。

## 開發狀態

本專案會依實際教學、學生操作情形與課堂測試持續修正。網站內容、任務流程、鷹架與模擬器可能隨版本更新而調整。
