STEM創課－解密四軸無人機 V2

V2 的學習主線

不是把舊課程推翻，而是讓每一個重要概念更能「用真實硬體證明」。
智高無人機負責成熟的真實飛行體驗；ESP32 開源無人機負責打開 PWM、Mixer、IMU、PID 與程式控制的黑盒。
系統與安全→結構與方向→單馬達 PWM→四軸 Mixer→IMU 姿態→PID 平衡→程控任務

M0～M6 新版任務地圖

目前先確認整體架構；各模組會依序建置，每完成一階段再進入下一階段。

M0

系統解密

一架四軸無人機裡藏了什麼？控制訊號怎麼流動？
從零件與子系統出發，加入人的控制意圖 → 飛控 → PID / Mixer → PWM → MOSFET → 馬達的訊號鏈，以及拆槳、Arm/Disarm、急停等共同安全規範。
下一階段建置
M1

機體結構

怎樣的「身體」比較穩？無人機怎麼描述方向？
保留對稱、剛性、輕量、防護與線路檢核，加入機頭方向、FL/FR/RL/RR、Roll/Pitch/Yaw 與 CW/CCW。
待建置
M2

動力解密

程式怎麼控制一顆馬達的動力？
以 ESP32 單馬達 PWM Lab 進行 Duty、啟動死區、氣流／推力與電池條件的探究，並保留必要的 PWM 概念鷹架。
待建置
M3

四軸協同

一個控制命令怎麼變成四顆馬達不同輸出？
從 Throttle / Roll / Pitch / Yaw 進入真實 Motor Mixer，以 FL/FR/RL/RR 預測、計算、量測與限制式機體驗證。
待建置
M4

姿態感知

無人機怎麼知道自己歪了？
使用 MPU6500 實際觀察 Acc / Gyro、Roll / Pitch / Yaw、漂移與六面校正，理解感測資料如何轉成姿態估測。
待建置
M5

智慧控制

歪掉了，機器怎麼自己修正？
以單軸／雙軸 PID 平衡架，把目標、感測、誤差、P/I/D、Motor Mixer 與再感測串成真正的閉迴路控制。
待建置
M6

程式任務

如何把飛行動作變成機器可以執行的程式？
先建立安全的時間式 Mission Executor，再由 Web、OSEP Scratch 或 Blockly 組合循序、迴圈與條件任務；在位置感測成熟前不宣稱精準距離／定點飛行。
待建置

預留延伸：位置感知與自主任務

E1｜位置感知預留 PMW3901 光流、VL53L1X ToF、BMP388 氣壓計、QMC5883L 磁力計。廠商硬體／韌體完成前，先用模擬器建立高度、位移與感測限制概念。
E2｜自主任務待定高、定點與航向感測成熟後，再加入距離式移動、定點、定高、航向修正與任務狀態機；目前主線只做可被現有硬體驗證的任務。

建置方式

V2 採逐階段確認：先確認這個首頁與課程架構，再開始 M0。M0 完成並由教師檢視確認後，才進入 M1，依序完成到 M6。
