# STEM創課－解密四軸無人機 V2

V2 是 `drone-steam` 的新版課程研發區。原根目錄 M0～M7 舊版教材完整保留，不直接覆寫。

## V2 重構原則

1. **保留原課程主線**：系統 → 結構 → 動力 → 四軸協同 → 感知 → 回授控制 → 程式任務。
2. **以實體證據鏈為核心**：能用 ESP32 開源飛控實際控制、量測、觀察的內容，優先轉為實體探究。
3. **雙載具策略**：
   - 智高無人機：成熟、安全的真實飛行與成品系統體驗。
   - ESP32 開源無人機：PWM、Mixer、IMU、PID、Web/Serial、程控任務等飛控黑盒解密。
4. **做的比寫的多**：每模組只保存必要的實驗證據、數據與統整，不把每個流程都變成線上答題。
5. **安全分級**：拆槳測試、限制輸出、Arm/Disarm、Emergency Stop、低電與斷線保護納入課程規範。
6. **位置感知預留**：硬體預留 I2C / SPI 擴充，未來可加入 PMW3901、VL53L1X、BMP388、QMC5883L；正式硬體與韌體完成前，以概念模擬或延伸模組呈現，不宣稱目前已具備精準定高、定點能力。

## V2 主線架構

| 模組 | 主題 | 核心問題 | 主要實體／數位證據 |
|---|---|---|---|
| M0 | 系統解密 | 一架四軸無人機裡藏了什麼？控制訊號怎麼流動？ | 智高＋ESP32 開源機、系統訊號鏈、安全狀態 |
| M1 | 機體結構 | 怎樣的「身體」比較穩？無人機怎麼描述方向？ | 對稱、剛性、重心、FL/FR/RL/RR、Roll/Pitch/Yaw、CW/CCW |
| M2 | 動力解密 | 程式怎麼控制一顆馬達的動力？ | ESP32 單馬達 PWM Lab、Duty、啟動死區、氣流／推力 |
| M3 | 四軸協同 | 一個控制命令怎麼變成四顆馬達不同輸出？ | Throttle/Roll/Pitch/Yaw → Mixer → FL/FR/RL/RR |
| M4 | 姿態感知 | 無人機怎麼知道自己歪了？ | MPU6500、Acc/Gyro、Roll/Pitch/Yaw、漂移、六面校正 |
| M5 | 智慧控制 | 歪掉了，機器怎麼自己修正？ | 單軸／雙軸 PID 平衡架、Error、P/I/D、串級控制 |
| M6 | 程式任務 | 如何把飛行動作變成機器可以執行的程式？ | Mission Algorithm Lab、Sequence／Loop／Condition、安全停止；AUTO 任務待韌體實作 |

## 建置流程

V2 採逐階段確認方式：

1. 建立 V2 架構與首頁。
2. M0 完成 → 使用者檢視確認。
3. M1 完成 → 使用者檢視確認。
4. M2 線上教材與 PWM 模擬先行；真實馬達數據與安全值待硬體採購後驗證。
5. M3 四軸協同教材與 Quad Mixer Lab 已完成；真實四馬達輸出與飛行反應待硬體驗證。
6. M4～M6 線上教材與 IMU、PID、Mission Lab 已完成；真實感測、控制與任務能力待硬體分級驗證。
7. E1／E2 先保留規劃入口，待硬體成熟再實作。

> 每一階段確認後才進入下一階段，不一次全面改寫。
