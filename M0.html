M0 任務題目

如果把這架無人機拆開，裡面可能藏了什麼？

核心提問：
這些不同部分各自負責什麼？又如何合作成一個能完成任務的科技系統？
看完整機體 → 猜想零件 → 配對功能 → 分類子系統 → 建立系統概念
01
猜想

看著任務主圖，你覺得拆開後可能有什麼？

先不要查答案。從下面選項勾選你認為無人機裡「可能會有」的部分。可以多選，也允許先猜錯。

04
統整

從一堆零件，看見一個科技系統

前面已經把零件依功能整理成不同子系統。現在直接用科技系統常見的「輸入 → 處理 → 輸出 → 回授（回饋）」來看整架無人機怎麼運作。

① 輸入 Input

系統收到什麼？
操作者／程式的任務命令、遙控通訊資料、電池提供的電能，以及感測器取得的狀態資料。
→

② 處理 Process

系統怎麼決定？
主控盒／控制板執行程式，解讀命令與感測資料，決定四顆馬達應該如何輸出。
→

③ 輸出 Output

系統做出什麼？
馬達帶動螺旋槳產生推力，使機體上升、下降、移動或旋轉。

④ 回授／回饋 Feedback

ToF、光流等感測器再次取得「現在的高度或移動狀態」，把資料送回控制端，讓系統知道實際結果。
實際狀態 → 感測資料 → 回到控制端 → 必要時再調整輸出
提醒：這是一張 M0 的簡化科技系統圖。M4 會深入「怎麼感測」，M5 才會深入「如何根據誤差自動修正」，現在先看懂整體脈絡即可。
把兩種觀點連起來：
「結構、能源、動力、感測、控制、通訊、程式」是在看系統有哪些功能；「輸入、處理、輸出、回授」是在看這些功能如何連成一個運作流程。
